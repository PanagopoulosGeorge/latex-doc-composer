# Chapter roles in a thesis

| Chapter | Job | Typical length | Common failure |
|---|---|---|---|
| Abstract | The whole thesis in 150–300 words: context, gap, approach, main result (with a number), meaning | 1 page | Describes the topic instead of the result |
| 1 Introduction | Problem, why it matters, research question, contributions with forward references, outline | 8–12% | Contributions that the evaluation doesn't back up |
| 2 Background | Only the theory and notation later chapters use. One running example | 10–15% | A textbook chapter: material nothing later depends on |
| 3 Related work | Group prior work by approach; contrast each group with yours | 10–15% | Annotated bibliography with no "unlike them, we..." |
| 4 Method | What you built, precisely enough to reimplement: overview figure, then components, design choices with alternatives | 20–25% | Mixing method with implementation trivia; unexplained choices |
| 5 Evaluation | Evidence for each contribution: RQs, setup, results per RQ (answer first), threats to validity | 20–30% | Results without interpretation; no baselines; one cherry-picked run |
| 6 Conclusions | Answer the RQ; revisit contributions; specific limitations; concrete future work | 3–5% | New claims; generic limitations ("more data") |
| Appendix | Supporting material referenced from the main text | as needed | Material nobody references |

## Order of writing (recommended)
1. Method and evaluation (what you actually did and found).
2. Background (now you know what the reader needs).
3. Related work.
4. Introduction and conclusions **together**, so they mirror each other.
5. Abstract last.

## The mirror test
List the contributions in the introduction. For each one, write down:
- the section that presents it (method),
- the table or figure that supports it (evaluation),
- the sentence in the conclusions that revisits it.

Any blank cell is a gap an examiner will find.

## Chapter openings and closings
- Opening paragraph: what this chapter does and why the reader needs it now.
- Closing paragraph (optional, useful in long chapters): what was established, and how the next chapter builds on it.
